# V2 LightGBM 第二阶段（选 M + λ 小网格 + 边界外延）结果

日期：2026-11-16。按计划第 7 节第二阶段步骤 1–3 与第 12 节修订执行；**未做精搜与 path_smooth，未进入第三阶段**。执行记录见 `LGBM_V2_WORKLOG.md`。

## 设置

- 五折外层 2017–2021，448 因子，无样本筛选，筛选流程；新增 2018、2020 两折缓存（同一套代码，manifest 校验通过）。
- 固定：lr 0.02、**上限 6000**、耐心 200、每 10 轮评估、早停指标 = 早停集全样本日度 Rank IC（不变），feature_fraction 0.3、bagging 1.0、max_bin 255、extra_trees 否、min_gain_to_split 0、seed 42、deterministic、8 线程。
- **主选择口径 = 资格池日度 Rank IC**；选择分数 = 五折均值 − 0.25 × 五折标准差（ddof = 0）；有资格池负折或任一折 best_iteration ≥ 5700（截断）的组合不能作为胜出组合。全样本口径并列报告。
- 保存全部轮数模型：`lightgbm_model_all_rounds.txt.gz`（`model_to_string(num_iteration=-1)`，gzip；LightGBM 中不传 num_iteration 时默认保存到 best_iteration，所以显式传 −1），`best_iteration.json` 另存 best。复用第一阶段的格子没有全轮数模型。
- 复用：λ = (0, 0) 且第一阶段在 3000 轮前早停的格子直接复用（2017 / 2019 深 0.1%、2019 中 0.1%、2019 中 0.25%）。为诊断需要，2021 年 λ = 0 的 4 个格子重新拟合，结果与第一阶段逐位相同（下表 F），实证了复用依据。
- 输出：`quant_data/processed/v2/lgbm_stage2/`（每个拟合一个目录，共 100 个；`m_selection.json`、`grid_state.json`、`fits_table.csv`、`m_table.csv`、`grid_table.csv`、`winner_pairwise_nw.csv`、`round_curves.csv`、`stage2_tables.md`、`stage2_summary.json`）。

## 结论

1. **M = 中 0.1%**（五折资格池分数 0.0788，无负折、未截断）；全样本口径同样选中 0.1%。中 1% 在 2017 年截断（best 5960）。
2. **复杂度诊断满足**：C（深 0.1%）实际平均叶子 511.0 vs M 74.3，比值 6.88（逐折 6.43–7.16），平均深度 35.5 vs 8。
3. **胜出组合 = 深 0.1%、λ1 = 10、λ2 = 1000**，资格池分数 0.0830（五折 0.1088 / 0.1069 / 0.0911 / 0.0649 / 0.0670），无负折、未截断；全样本分数 0.0815（全样本排第 3）。
4. **未触发边界外延**：胜出点 λ1 = 10、λ2 = 1000 都在网格内部。
5. 相对 C 的无正则（λ = 0，0.0812），胜出组合高 0.0018，配对 t = 2.84；增益主要来自 2019 年（0.0823 → 0.0911）。
6. 18 个组合的资格池分数集中在 0.0782–0.0830 之间，差距很小。

## 平台规则与邻域检查的初步观察（只作观察，不作选择）

- **与胜出组合差异不显著（|t| < 2）的有 7 个**：深 (50, 1000) t 0.51、深 (10, 0) 0.60、深 (50, 0) 1.17、中 (10, 0) 1.17（截断，不能入选）、深 (0, 10000) 1.48、中 (10, 1000) 1.48、中 (50, 0) 1.87。按第 8 节第 4 条平台规则，应在这些组合中偏向更简单 / 正则更强的：
  - 同一结构内，深 (50, 1000) 正则更强、实际叶子少得多（180 vs 490，深度 22.9 vs 26.7），t = 0.51，且在全样本口径排第 1。
  - 跨结构，中 (10, 1000)、中 (50, 0) 更简单（约 67–83 叶、深度 8），与胜出组合不显著（t 1.48、1.87），但 2021 年对 Elastic 的配对 t 仅 1.23–1.40。
  - 平台规则本身是第 8 节的选择规则，是否在第二阶段精搜前就套用、套用到哪个层级（结构内 / 跨结构），需要评审决定；我没有据此改变胜出组合。
- **邻域检查**：胜出点 (10, 1000) 的相邻格子——(50, 1000) 0.0827、(10, 0) 0.0824、(0, 1000) 0.0808、(10, 10000) 0.0810——都接近最优，没有孤立尖峰；λ1 方向（10 ↔ 50）平坦，λ2 = 10000 一侧略降。

## 可疑之处与需要评审判断的问题

1. **截断只来自 2017 年一折，且全在中结构**：中 (0, 1000)、(10, 0)、(10, 10000) 与中 1%（λ = 0）在 2017 年 best_iteration 为 5880–6000，其余四折都低于 4900。截断规则按“任一折”执行，使中 (10, 0)（资格池排第 6）失去入选资格。2017 年训练期（2011–2015）收敛明显最慢，加 λ 后更慢。
2. **外层最优轮数远早于早停点（2020 折尤其明显）**：用全轮数模型逐 100 轮看外层资格池 Rank IC（表 G），2020 年四条曲线的外层峰值都在 100–400 轮，而早停 best 为 380–1600 轮，早停点比峰值低 0.005–0.009（例如 2020 中 (10, 1000)：峰值 0.0702 @ 400 轮，早停 1600 轮时 0.0626）。2021 年早停点基本在峰值附近。也就是说，评审担心的“单年早停集过早停止”在这两折**没有出现**，反而 2020 折是“停得偏晚”。只作诊断，不用于选择；第四阶段的早停变体可以针对这一点。
3. **过拟合差距没有因为 λ 明显缩小**：胜出组合内部拟合 − 早停 Rank IC 差仍为 0.262（λ = 0 为 0.266）；只有 λ1 = 50（深结构叶子减到约 180）或 (10, 10000)（约 420 叶）时差距降到 0.12–0.16。λ1 = 10、λ2 = 1000 的量级对深结构影响很小，叶子数仍约 490。
4. **2021 年对线性对照仍不显著**：胜出组合在 2017–2020 对同折 Elastic（资格池）t 为 3.8–6.0，2021 年 t = 1.71。2021 年 t ≥ 2 的只有深结构 (0, 10000)、(10, 10000)、(50, 1000)、(50, 10000)（2.01–2.18；(50, 0) 为 1.95）。
5. **全样本与资格池口径的排名分歧**：全样本第 1 是深 (50, 1000)，资格池第 1 是深 (10, 1000)；两者 t = 0.51，属于同一平台，结论不受口径影响，但“哪个是第一”依赖口径。
6. **耗时**：深结构单次最长 1964 秒（2017、λ2 = 10000），平均每组合 5 折约 30–70 分钟；单次拟合时间已明显超过样本量决策时的 10 分钟假设（按计划不再改样本量）。峰值内存最高 9.1 GB。

## H. 第二阶段后离线诊断（2026-11-16，评审修订第 13 节；不新增拟合，只诊断，不用于选择）
