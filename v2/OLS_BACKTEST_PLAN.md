# OLS历史模拟固定方案

查看收益结果前固定：只用已完成2017–2023年OLS逐年预测，不训练或调参。每年1亿元初始资金、前50只、5组轮换，信号日收盘后选股，下一交易日开盘买入，第5个未来交易日收盘计划卖出。

沿用已有筛选：信号日成交额至少5000万元，上市至少60个自然日。先排名，随后判断成交；不按未来标签是否可用筛掉候选。未成交保留现金、不递补。停牌/一字跌停延迟卖出，整组资金等待最晚退出；未退出头寸年末估值，年度独立重置，不构造连续可交易跨年曲线。

两组往返基础成本20bp和50bp，买卖分配25%/75%，另外双边各收0.5×过去20日波动率×sqrt(订单预算/信号日成交额)的冲击代理。订单预算最多占信号日成交额5%。这些是固定情景假设，不是逐年实际费税或成交日容量保证。

输出各年收益、最大回撤、日频Sharpe、双边年化换手、订单成交/拒绝原因、延迟退出及年末未退出数。逐笔核对买入预算=买入名义金额+成本，核对NAV和每日收益恒等式。保留本地股票池幸存者偏差、日线撮合、缺失涨跌停、无ST历史及整手约束等限制；不据此声称实盘盈利或超额收益。
