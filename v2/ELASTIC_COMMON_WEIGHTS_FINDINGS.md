# Elastic共同训练池实验结论

后续逐行复核发现，早期广义池按时间戳计算抽样 hash，本轮共同池按日期计算。固定训练池与种子后，两种抽法每折 50 万行只重合 6.23% 至 17.13%。因此下文跨轮收益差还包含抽样顺序的影响。本轮两种日期权重的组内比较使用相同样本。统一日期类型后的四组对照见[训练样本筛选实验](../reports/v2/elastic_gate_ablation/REPORT.md)。

本轮完成7个年度、14次拟合和4组连续交易模拟，结果见[完整报告](../reports/v2/elastic_common_weights/REPORT.md)，实现见[训练及回测代码](run_elastic_common_weights.py)。

两组共用每折50万条训练数据，仅改变日期权重的每日股票数量参考。使用完整共同池计数，原冲击下七年累计净收益从26.08%升至29.19%，增加3.10个百分点；双倍冲击下从5.75%升至7.83%，增加2.08个百分点。日均Rank IC反而由0.067662小幅降至0.067380，因此本轮排序相关性与策略收益没有同步变化。双倍冲击下最大回撤仍约42%。这些结果没有统计显著性或未见测试支持，不据此冻结最终模型。

上一轮广义V2训练池、抽样计数、V1正则化规则的累计净收益为−5.27%和−25.79%。本轮相同计数与正则化规则下达到26.08%和5.75%，显示样本选择值得优先检查。这个跨轮变化同时包含训练池门控和固定hash抽样后成员的变化，不能单独归因于某一道门控。

尤其需要注意，共同池继承V1的target_valid，涉及未来成交状态；这类筛选改变了模型所见样本分布。不能据此声称使用未来信息进行样本筛选可以改善可部署策略，也不能将本轮结果直接替代无此筛选的V2候选。

下一步优先做训练样本门控消融：在同一广义V2训练池和固定hash优先序下，分别考察不加门控、仅旧50因子有效数至少30、仅target_valid、两者同时成立。固定19因子、既有训练折预处理、V1正则化规则以及完整参考池日期计数。为单独识别样本门控影响，日期计数使用同一未门控参考池，不随分组改变；同时记录每组样本重合率。含target_valid的分支仅用于历史诊断。首先比较逐年Rank IC与残差，再用同一严格成交及成本规则检验交易结果。该消融尚未执行。
