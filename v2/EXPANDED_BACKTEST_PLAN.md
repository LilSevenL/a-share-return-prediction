# 50万样本连续回测

使用已核验的 expanded_losses_500k 保存预测，2017–2023 七折、每折50万训练行。完整448因子、精简333因子各运行Huber和MAE，共四候选。仅使用本地历史数据，不访问Tushare、不修改V1、不读取2024年及之后的行情。

沿用 compact_continuous 的模拟引擎和全部规则：初始1亿元，跨年不重置；五组轮换、每组前50；固定5日退出、前50保留、前100保留；gross、20bp往返基础费加冲击、50bp往返基础费加冲击，共36场景。资格、容量、涨跌停处理、现金复用、末期持仓估值保持相同。

先核对源文件和输入元数据，逐场景独立核对现金及年度末持仓，再对保存净值重算收益、回撤、年度复利。完整与精简、20万与50万均按同损失、同退出规则、同成本匹配报告，不挑选有利场景。

这是重复查看历史开发集后的扩样本比较。Huber目标尺度随新样本重估；结果不能纯归因于样本数量，也不能作为未来盈利证明。幸存者偏差、日线成交、缺失涨跌停、无历史ST及整手约束等既有局限仍适用。模型暂不定版。
