# 精简候选与统一连续交易评价

依据已查看的单组消融，固定候选为同时移除C条件筛选与M动量反转组；其余输入沿用原训练期预处理。每折448活跃输入减去115列，剩333列。训练2017–2023七折，各20万行，等权Huber和精确MAE，L2=0、delta=1.35、tol=1e-5、max_iter=6000。复用完整模型作为对照。此为历史开发候选，不是新独立检验，不因结果调整删组组合。

交易评价对完整/精简×Huber/MAE四组信号使用相同市场、股票资格、前50选股、初始1亿元、五组现金轮换、跨年连续账户、fixed5/keep50/keep100三种既有退出规则，以及gross/cost20/cost50三种既有成本场景，共36组。成本20/50bp加原冲击参数0.5。所有场景完整报告，不只挑最好规则。独立重建现金和年末持仓。仅使用本地2017–2023行情，不读取2024以后退出价格。

组合删组的结果需实际训练，不能相加单组增量。预测与扣费表现分别报告，暂不替换最终模型。幸存者偏差、日线撮合、缺失涨跌停、无历史ST与整手约束等既有局限继续适用。
