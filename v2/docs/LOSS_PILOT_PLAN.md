# OLS / MAE / Huber首折试运行

在查看结果前固定：2011–2016训练、2017验证。训练只使用退出日在2017年前的有限raw五日标签，不按未来可交易性过滤；按hash(ts_code,signal_date,20261025)排序固定抽取200,000行，三种模型使用完全同一批数据。

预处理直接复用2017 OLS折的训练期拟合参数（该预处理基于训练期固定50,000行估计），448个活跃因子。三种模型均样本等权、带截距、L2=0。因此MSE是真正的OLS，不与Ridge混淆。MAE为未平滑绝对损失，ADMM求解；Huber的delta=1.35，以本次相同训练样本的1.4826×MAD目标尺度换算，不用验证期调整。统一tol=1e-5，max_iter=6000，未收敛不进入比较。

本轮目的为检查鲁棒损失求解收敛、计算成本及首折端到端比较，不代表全量样本结论。之前全量OLS保留，不将不同训练样本量的结果当作纯loss增量。先检查既有独立公式/线性规划测试。

预测2017全部因子行，仍仅评分未跨2018且标签有限的行。使用一致的等权及固定事前波动权重Rank IC。交易对照沿用三种已固定退出规则（fixed5/keep50/keep100）和gross/cost20/cost50，共3模型×9场景；全部模型都只模拟2017，现金与持仓年末处理完全一致，不与七年连续回测混为一谈。

不选最优损失、delta、权重或退出规则，不自动替换正式模型。后续是否扩展到全量与其余年份，先依据求解收敛和资源需求评估，不依据首折收益挑选赢家。幸存者偏差、日线成交、缺失涨跌停、入口冲击代理、无历史ST及整手限制继续适用。
