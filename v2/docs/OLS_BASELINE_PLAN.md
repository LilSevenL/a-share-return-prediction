# 修复版数据的OLS基准方案

在查看本轮结果前固定：训练起点2011年，验证年份2017–2023，按年扩展训练；OLS带截距、样本等权、MSE、无L2正则化。不比较损失函数或挑选超参数。

只读取 `local_features_2011_2023_stable` 和对应年份已有标签；保留V1和2024以后数据。标签为信号日收盘后，下一市场交易日开盘买入，第5个未来市场交易日收盘卖出的复权对数收益。训练标签退出日必须早于验证年起点；验证评分的退出日必须早于验证年结束。使用raw标签，不按未来能否交易筛选样本。

每折从训练数据按固定哈希选最多50,000行拟合预处理：最低覆盖20%，1%/99%裁剪，中位数填补，均值/标准差标准化，相关系数绝对值至少0.9995的重复信息按固定因子顺序剔除。沿用现有研究设置，不按本轮验证成绩调整。80%审计覆盖阈值仅为诊断，不等于训练筛选阈值。

预处理使用样本估计；OLS系数使用所有合格训练行，不对训练拟合抽样。按月份读取、每批20,000行，累积增广QR，再对小矩阵做SVD求解；避免全量矩阵占内存或通过正规方程放大条件数。每个月保存可恢复检查点，记录数值秩和条件数。

预测所有验证期因子行，评分仅对可用且未跨界的标签。输出每日等权Rank IC、固定口径加权Rank IC、IC、RMSE和MAE。加权指标只作补充，训练本身仍为等权OLS。本步不模拟交易，不把预测分数解释为实际盈利。所有结果属于仍有幸存者偏差的本地样本研究，不能称为独立未来测试。

训练前检查标签主键、市场交易日对齐、1,000条标签与源价格独立复算，并检查内存预算；训练后核对行数、因子绑定、数值秩和每折输出。
