# 持仓缓冲诊断结论

63组固定对照已完成，原OLS和既有策略均保留，未自动选取最优规则。详细结果在 `quant_data/processed/v2/ols_low_turnover/LOW_TURNOVER_REPORT.md`。

## 已观察到的变化

在20bp基础费加既定冲击成本下，保留前50与前100规则均改善七年的模拟净收益。前100规则的七年平均双边年化换手从固定5日的94.47倍降至70.78倍（约下降25.1%）；平均每年记账费用从1686万元降至1240万元。各年份初始资金独立重置为1亿元，费用含基础费与冲击。

| 年份 | 固定5日净收益 | 保留前100净收益 |
|---|---:|---:|
| 2017 | 3.13% | 8.05% |
| 2018 | -21.07% | -19.25% |
| 2019 | 1.54% | 9.46% |
| 2020 | -9.52% | -1.46% |
| 2021 | 6.33% | 7.41% |
| 2022 | -1.52% | 1.51% |
| 2023 | -10.10% | -2.58% |

持仓缓冲减少交易、改善了当前成本假设下的结果，但不能将全部净收益差额解释为费用节省。零成本毛收益有升有降，例如2018年前100毛收益比固定5日更低；规则也改变了市场风险敞口和复利路径。

## 尚未解决的问题

前100规则在20bp场景仍有三年亏损；50bp场景七年均亏损。不能声称已找到稳健可交易策略。

前100规则已结束批次的平均持有时长约6.88个交易日（先算各年均值再平均），超过训练标签的5日持有口径。年末仍有34–130个未退出批次、约1254万–3568万元持仓市值。这些只是年末估值，未假设已卖出，也未扣除假设清仓费用；批次数不等于不同股票数。

本次延续同股票可跨批次重复买入的设置，以单独对照退出规则，因此不等于完整的持仓去重或最小换手调仓系统。卖出冲击仍使用入口时的事前估计。原有幸存者偏差、日线可成交假设与历史信息限制继续存在。
