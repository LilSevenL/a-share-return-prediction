# 七折股票训练权重对照（运行前固定）

目标：在损失函数固定时，区分日期平衡与股票差异化权重的增量。沿用2017–2023七折，每折原20万行样本、原预处理与原目标尺度。原等权三损失共21模型复用；新增日期权重、日期加股票权重，各训练OLS/MSE、Huber、MAE共42模型。MSE加权后称WLS，不再称普通OLS。

三组权重：
1. uniform：所有样本相同（上一阶段结果）。
2. date：训练样本内当日行数N_t，单行权重为N_t^(-0.75)，全体均值归一为1。这是日截面样本数量平衡，不是近期样本衰减。
3. date_stock：date乘以过去20日波动率构造的股票系数，先除同日训练样本有效波动率中位数，指数固定1；通过有界归一使同日系数均值为1、范围[0.5,2]。缺失/非正波动率先赋原始系数1，再参与同日归一。没有用未来实现收益，也没有直接按行业标签偏好某类股票。

date_stock保持date组每天总权重不变，二者差异因此来自日内股票侧重。系数上限是股票乘数的上限，不是与日期权重相乘后全局样本权重的上限。额外报告有效样本量、缺失波动率、乘数分布以及每日总权重一致性。

训练固定L2=0、Huber delta=1.35、tol=1e-5、max_iter=6000、4线程。不根据这轮分数调权重强度、筛选模型或改变预处理。不按未来可交易性过滤训练样本。以同一年度全部验证股票构造公共评价波动权重，并且所有模型都报告普通Rank IC和同一定义的加权Rank IC；允许在同一评价口径下比较，不混用不同权重定义的分数。

“加权Rank IC”在本项目具体指：先对预测与真实收益分别取普通截面秩，再计算用共同事前股票权重加权的Pearson相关。它并非加权分位秩变换。它与普通Rank IC均只是预测诊断，最终经济效果仍需相同交易规则、成本和连续资金账户的回测。

沿用仅本地数据与2011–2023范围。500候选中的缺失因子门控不变，不能据此声称使用500个有效因子或全量训练。沿用MAE完整状态恢复、Huber系数温启动，并把权重哈希纳入检查点身份。所有新结果单独存储，旧结果和V1保持不变。
