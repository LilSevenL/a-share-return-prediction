# OLS七折因子组消融

运行前固定：2017–2023，每折沿用multiyear_losses_200k的20万行训练样本、标签、等权及训练期拟合预处理。第一阶段只用OLS/MSE，L2=0。逐一移除M/R/L/P/F/X/Q/V/C/I家族，其他家族保留；C是35个conditional filtering因子。每个子模型重新拟合截距和全部保留因子的系数，不能简单把完整模型的部分系数置零。

保持既有截尾、填补、缩放和相关性筛选结果，只对活跃输入做删列。这衡量给定预处理下各组的条件增量；未重新筛选相关因子，也不衡量该组单独预测能力。某组没有活跃输入时标为不可检验，不把零差值解释成无价值。

使用完全相同验证键、标签和公共事前波动评价权重。报告完整模型减去移除组模型的日均Rank IC差、年度差和改善年份数；正差说明完整模型更好。报告RMSE/MAE，同时保留逐日指标与预测以供交易回测。全模型重新拟合与之前等权OLS核对，独立重算各消融模型Rank IC。

只使用本地2011–2023数据。所有结果作为历史开发证据，不自动按这些分数删除因子或选最终模型；鲁棒损失复验、因子组合精简及交易回测另行进行。
