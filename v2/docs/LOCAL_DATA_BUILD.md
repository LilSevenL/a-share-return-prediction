# 本地已有股票的分块因子生成

## 本轮已完成结果（2026-10-25）

后续研究应读取 `quant_data/processed/v2/local_features_2011_2023_stable/`，不要读取未修复的父目录作为训练输入。

- 2011–2023年，9,316,878条股票日期、5,076只股票、156个月度分区，最终Parquet约16.74GB（十进制）。各年行数均与本地源数据一致。
- 500列候选结构，449列可计算，51列继续隔离；每一年均有449列产生有效值。
- 原始长历史运行暴露滚动峰度缺失/数值差异、趋势R²的一个缺失差异，以及3日收益—成交量相关系数越界。因此另存稳定版本，独立重算4个峰度、4个趋势R²及1个相关系数，保留原始输出供追溯。零方差窗口的峰度、R²及相关系数定义为缺失。
- 404项真实股票窗口与SciPy/NumPy独立公式核对通过；17项相关测试通过。466列未改动的非交互因子，在38,623条参考记录上值及缺失掩码全部一致。25个交互列因股票池不同不与80股参考直接比较，9列修复值单独按独立公式验证。
- 156个月份重复键及无穷值检查通过；数学范围异常为0。1,053个因子—年份提示全部来自覆盖率低于80%，没有常数列或全年全空的非隔离因子。提示不是1,053个不同因子，也不作为全期删因子的依据。
- 2023年的20项低覆盖提示全部位于盈利收益率、股息率及其衍生/交互项；具体见年度明细。早期年份另有较广泛的低覆盖，需要在训练折内按字段缺失、上市/停牌历史及预热长度归因。
- 尚未训练、调参或进行收益模拟；未使用2024及以后的数据。当前本地股票池仍有幸存者偏差。

详细结果：修复目录下 `QUALITY_REPORT.md`、`quality_summary.json`、`reference_parity.json`、`independent_numeric_checks.json`。`repair_manifest.json`记录父数据及执行代码哈希；`repair_source_executed.py`保存实际运行的修复脚本。修复脚本随后仅增加自动创建质量输出目录；哈希不一致时恢复保护仍会拒绝混写。

下一步：先接入修复数据，按训练折确定覆盖率筛选、缺失填补和标准化，并检查标签时间对齐及OLS内存预算，然后跑OLS基准。当前生成器解决的是因子数据分块，不代表训练程序已支持全量流式拟合。

入口：`v2/features/build_local_features.py`。只读2010–2023本地源数据；2010用于预热，默认输出2011–2023。不调用Tushare、不读取目标收益、不读取2024确认期或2025以后Test，不修改V1。

当前任务是生成数据，不训练模型或优化参数。股票池是本地已有的历史记录，仍有已知幸存者偏差；所有产物标记为`local_survivor_research`，不能称为完整历史市场。

## 分块与恢复

1. 按源年份读取所需字段并连接日线、复权、日指标和资金流，写入按股票桶划分的临时Parquet。DuckDB内存上限4GB。
2. 每个股票桶最多64只股票，使用8个独立计算进程。每只股票在自身完整市场日索引上计算修复后的因子，按股票日期保留历史，不对停牌价格或资金流前向填充。
3. 中间结果按年份保存；参与交互截面排名的父因子保留float64，其余存float32。整个截面到齐后计算交互，最终月度表存float32。数值计算本身仍为float64。
4. 逐月只加载一个完整股票截面月份，检查键、无穷值和51项隔离。完成后的年度中间缓存清理，降低磁盘峰值。
5. 年度暂存、股票桶、最终月份均有原子检查点；已完成的输出不重复计算。代码、输入文件或配置变更时拒绝在原目录混写。

所有中间清理只针对当前输出目录下的指定暂存路径，不删除源数据。保留至少8GB磁盘空间；触及空间限制时停止并保留检查点。完成汇总前重新核对月度输出存在及其行数，最终总行数必须与源股票日期数相符。

## 输出

- `build_config.json`：配置、源码哈希、输入文件清单、已知股票池限制。
- `progress.json`：当前阶段与已完成年份/股票桶/月份。
- `feature_year=YYYY/month_MM.parquet`：股票、日期、500候选列及有效列计数。
- `quality/YYYY-MM.json`：每月逐因子有效数、缺失数、范围与键检查结果。
- `feature_report.json`：仅在整批完成并核对行数后写入，含整体覆盖率与449/51状态。

默认生产命令：

```powershell

```

断点恢复使用完全相同的命令。不要把`progress.json`存在或部分月份输出误认为整批已经完成。

本轮质量统计仅作数据质量诊断，不能用全期统计来筛选alpha、填补训练数据或标准化；这些参数仍应在后续各训练折内拟合。
