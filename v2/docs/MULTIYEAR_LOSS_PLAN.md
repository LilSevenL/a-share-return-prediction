# 多年份同样本损失函数比较（预先固定方案）

本阶段覆盖2017–2023七个历史开发验证年份，每折训练期从2011年开始，到验证年份之前结束。训练标签退出日必须严格早于验证年1月1日。每折按固定hash(ts_code,signal_date,20261025)抽取200,000行，同折OLS、MAE、Huber完全共用；不因2017结果筛选损失函数。不增加样本量，先隔离跨年份稳定性问题。不是全量训练，也不将已看过年份称为独立未来测试。

预处理复用各年度既有OLS折仅用训练期拟合的参数。固定等权、L2=0、Huber delta=1.35、tol=1e-5、max_iter=6000、4线程。训练目标尺度每折按同一训练样本计算。未收敛拒绝进入有效比较。验证全年预测，评分只使用原OLS折保存的有限标签，所有损失共用相同键和评分样本。

报告每年及按有效交易日汇总的Rank IC、统一事前波动权重Rank IC、RMSE和MAE。不根据验证收益调整参数。交易回测属于后续统一执行阶段，本阶段不重跑各模型的交易模拟。

MAE每100迭代保存完整theta/z/u/迭代号，恢复后延续相同ADMM迭代。Huber每100迭代保存系数，恢复时保留剩余迭代预算，但重新建立L-BFGS曲率历史，因此是明确标注的温启动，不保证恢复路径逐位一致。已完成的模型/预测阶段可以跳过。文件、代码及样本身份变化时拒绝复用检查点。数据和代码快照写入新输出目录，既有结果保留。

仅使用本地2011–2023因子与目标数据，不请求Tushare，不读取2024年及以后行情。幸存者偏差、缺失财务因子等既有数据限制继续适用。500候选因子不等于500有效输入，各折实际输入数量由既有预处理记录决定。
