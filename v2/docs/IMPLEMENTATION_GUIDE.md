## 每部分怎么做

| 部分 | 研究决定 | 本轮落地 |
|---|---|---|
| 因子 | 信息方向优先于机械枚举；500 是候选预算，不是必须投入回归的数量 | `balanced_features.py` 实现当前平衡目录；`build_balanced_features.py` 计算并保存月度特征 |
| 条件筛选 | 作为额外特征，后续做有/无该类因子的消融；不预先删除整个股票样本 | C 类35项；包括按历史成交活跃度、大单流选择窗口内日期 |
| 日内结构 | 日线可拆隔夜/开收盘收益、振幅与影线；无法知道最高价与最低价先后 | 已实现日线可识别结构；不伪造分钟路径 |
| 财务时点 | 必须证明当时可获得的版本和可比报告口径 | Q类45项及5项相关交互隔离为空；不填成假信号 |
| 预处理 | 只在训练期拟合缺失值、截尾、标准化和冗余筛选 | 覆盖率至少20%，1%/99%截尾；常数及绝对相关系数>=0.9995的后续列剔除；固定种子最多5万训练行估计 |
| 损失 | 保留真正OLS控制；用同一正则口径对比MSE/MAE/Huber | OLS无权重且lambda=0；另外9组共同lambda=0.01，Huber delta=1.35，均为初始实验值 |
| 股票权重 | 用信号日已知风险描述重要性，不能用未来涨跌确定权重 | 历史20日波动率相对当日中位数，幂次p=0/0.5/1，最终倍数限制[0.5,2]，每日平均为1 |
| 时间权重 | 保留现有日期平衡规则，避免新增股票权重同时改变日权重 | 每行日期项N_t^(-0.75)；每日总权重仍正比N_t^(0.25)，不是严格日等权 |
| 预测评价 | 所有候选使用同一股票池、同一标签、同一把尺子 | 普通Rank IC、固定p=1加权Rank IC、IC、RMSE和MAE；每天IC再等权平均 |
| 交易评价 | 股票训练权重不直接变成持仓权重 | 相同Top50、五袖套、下一日开盘买入/第5日收盘卖出、未成交现金、延迟退出和成本 |
| 选择参数 | 先验证实现，再按时间验证，控制搜索次数 | 本轮固定参数并记录来源；未用结果自动挑选参数或赢家 |

高波动加权是一个待验证的经济假设，不是通用正确答案。高波动也可能代表噪音、更大风险和更高冲击成本。Huber降低大残差的边际影响；波动权重提高某类股票的重要性，两者可以同时存在，但需通过三损失×三权重的共同对照识别效果。

## 权重与共同尺度

令sigma为信号日历史20日波动率。每天先计算 raw=(sigma/median(sigma))^p；缺失/非正波动率的raw暂取1。求一个当日常数c，使mean(clip(c*raw,0.5,2))=1。这样最终权重同时满足上下限和日均1，而不是先截尾再归一化后突破上限。缺失样本的最终倍数不保证恰好1。

训练权重为日期项乘股票倍数，最后整体平均归一为1。三个损失都使用相同训练标签的MAD尺度和一致的L2定义；截距不正则化。MAE是精确绝对误差目标，Huber是标准分段损失。没有收敛就报错，不能把失败拟合当作有效结果。

加权Rank IC定义为**普通平均秩之间的加权Pearson相关**；不是另一种重新加权排序法。评测权重固定p=1，同一天所有模型一致，因此普通与加权模型均可公平比较同一列指标。排名相关仍不能替代收益、回撤、换手和成交能力评价。

## 时间与标签修正

训练标签仍是下一市场交易日开盘至第5个未来市场交易日收盘的复权log return。本轮使用`target_logret_5d_raw`的有限值，不使用需要未来买卖均可成交的`target_valid`筛选训练样本。训练标签的退出日必须严格早于验证期起点，避免标签跨界。

验证预测覆盖所有信号日特征行，再对可观察的标签计算指标。未来停牌/涨跌停只影响模拟成交，不能提前参与选股。标签缺失和期末跨界行单独计数。即便如此，原始价格缺失仍可能带来样本选择问题，尚未对退市回收价值等建立专门处理。

新增滚动因子按完整市场交易日重建索引，缺失交易日打断窗口；追加未来数据不得改变历史因子。原50列中非财务部分沿用V1提供的数值，未统一改写其既有缺失口径；后续可单独进行旧因子口径审计。行业/历史成份股中性化不在本轮实现范围。

## 同一交易模拟

- 初始资金1亿元，五个等资金袖套，Top50等金额订单；不足50只或未成交的额度留现金，不重新分给已成交股票，也不事后找替补。
- 信号日成交额至少5000万元，上市至少60个自然日；订单/信号日成交额不超过5%。上市日期缺失的股票不进入模拟。
- 一字涨停等不可买状态不成交；停牌/一字跌停导致退出延迟，袖套全部退出前不建立下一批仓位。期末未退出仓位按最后可用价估值并记录。
- 单边冲击代理为0.5*sigma20*sqrt(订单金额/信号日成交额)，另加固定往返20或50bps，买入分配25%、卖出75%。这是统一的研究成本情景，未按分钟成交校准，也不是逐笔税费精算。
- 年末已知无法在本评价期内完成计划持仓的新订单不建立。跨年袖套没有连续滚动；逐年模拟重置资金，因此不能直接当作连续多年实盘组合。
- 输出净值、每日收益、每笔订单状态、成本、参与率、实际退出日、回撤、Sharpe和双边成交额/AUM。年化按252交易日。日线代理无法证明开盘实际可成交数量；严肃容量评价仍需更细成交数据。

## 已执行的工程验证

特征入口：`v2/features/build_balanced_features.py`；研究入口：`v2/experiments/run_research.py`。

- 数据：按代码排序的前80只股票，2022–2023；这不是代表性抽样。市场背景仍按完整源股票池计算，交互截面在该80只样本内计算。
- 输出38623行、500列；450列有数据，50列隔离。训练预处理后447列有效。
- 2023验证：18857条符合时间边界的训练行中固定随机抽1500条用于求解；预处理和权重统计基于该折完整训练样本。19337条预测，18917条可评分，420条不评分。
- 完成1组OLS＋9组损失/权重模型，每组20/50bps两个情景，共20组模拟。
- 8项损失数值测试和7项流程测试通过。包括与独立最小二乘/线性规划/二次规划比较、梯度、未来追加不改变过去因子、缺失交易日、权重边界和日总量、不成交留现金、不用低排名替补、成本/容量/延迟退出。
- 结果目录：`quant_data/processed/v2/research_integration_with_ols/`。早先不含OLS的`research_integration/`仅保留为运行记录，不作为当前完整对照。

不能用这些样本结果决定最终loss、股票权重、收益预期或上线。没有完成全市场七折训练、财务版本审计或分钟级执行校准。

## 后续正式研究顺序

1. 补齐历史财务版本/公告可用日与同比季度口径审计后再启用50个隔离候选。未通过时明确使用450个可计算候选。
2. 扩展股票池和年份前处理内存：当前求解虽支持分块运算，研究入口仍把该折原始表载入内存；已经增加预算检查，超限会提前停止。`--max-train-rows`只限制求解行数，不能减少加载内存。千万行全市场任务需要磁盘映射/流式预处理与训练，尚未实现，不能直接宣称具备全市场生产容量。
3. 按2017–2023时间折进行共同口径实验，优先比较原50中可审计子集与扩展集，然后做因子方向和filter消融。原50完整版本含被隔离财务项，不可偷偷换口径比较。
4. 在内层按时间分割选择lambda、Huber阈值、权重幂次；内层同样清除跨边界标签。外层只评价，不同时用来挑参数和宣称无偏收益。本轮只实现固定配置比较，未实现嵌套调参调度器。
5. 在相同股票池、同一成本与组合规则上看跨年稳定性、收益/回撤、换手与风险暴露，再冻结配置。已经看过的2024以及2025–2026历史结果不再是全新独立检验；最后必须使用冻结后的真实forward test。
