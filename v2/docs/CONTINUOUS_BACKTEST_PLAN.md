# 跨年连续账本方案

使用已保存2017–2023年OLS逐年预测，不重新训练。初始资金仅在2017年第一个交易日设置为1亿元；五组轮换按全期交易日索引连续计数，跨年不重置现金、旧持仓、待卖指令或复核计时。新年出现的信号来自相应年份已完成的模型，旧持仓从此使用同一新信号的昨日排名复核。

固定比较三种规则（5日退出、前50保留、前100保留）及三种成本（零成本、20bp加冲击、50bp加冲击），共9组。复核时间、现金复用、独立批次允许叠加、信号日容量代理均沿用上轮。2017–2022年末允许计划跨年退出的新仓；仅禁止计划退出超出2023年最后市场日的新仓。

每年收益按上年最后净资产为基准，全期收益来自真正连续模拟，不拼接年度重置曲线。输出年度末现金/持仓及持仓批次数、跨年成交、末期未退出持仓、全期回撤、换手与费用。独立重建现金流水，并以订单份额×年度末价格核对持仓市值。

2023年末未退出持仓继续按末日可用价格估值，不凭空清仓或读取2024年价格。延长持有的卖出冲击仍用入口时估计；停牌使用最近收盘价估值。既有幸存者偏差、日线撮合、缺失涨跌停、无历史ST及整手限制继续适用。结果属于事后历史研究，不是新的独立测试。
