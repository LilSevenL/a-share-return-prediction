# 成交假设收紧对照

固定50万样本精简Huber/MAE、2017–2023、1亿元初始资金、20bp往返基础费、0.5冲击系数，以及原三种退出规则。比较baseline、strict_limits、strict_limits_lots，共18场景；不覆盖或修改原引擎及V1。

strict_limits：执行日上下限价格均须有效；开盘价必须严格低于涨停价才允许买入，收盘价必须严格高于跌停价且当日有成交量才允许卖出。缺失限价并不等于一定禁止交易，本实验采用保守的不成交假设，可能排除合法无涨跌幅限制日期。无法卖出时持仓继续估值，资金不提前释放。信号排名不因这些执行条件重新排序或补位。

strict_limits_lots：在严格限价处理基础上，对买入原始股数向下取整。沪深普通股票100股整数倍；688科创板200股起、1股递增；北交所2021-11-15起100股起、1股递增，更早北交所代码或未知市场拒绝。用未复权开盘价计算股数，再将实际投入金额换算为复权份额用于估值；未花费余额留在现金。仍按原分配预算计算冲击和容量，以避免把成本改善混入数量取整效应。

仅实现买入数量粒度，并非完整交易所撮合：订单上限/拆单、公司行动后卖出实股数量与零股清算、价格笼子、历史ST、最小佣金、日内队列仍未重建。三类板块没有统一按100股处理。

核验：数量边界、原始价/复权价换算与现金余额、无法卖出时延迟；6个基准净值精确复现；每次成交核对执行日限价条件；18场景逐笔现金和年末持仓对账，保存净值独立复算。
