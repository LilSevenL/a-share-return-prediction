# 固定持仓缓冲对照

本轮在查看结果前固定三种退出规则：固定5个交易日；第5日若仍在资格池前50名则继续持有；第5日若仍在前100名则继续持有。保留时每隔5个交易日再复核，排名始终用复核日前一交易日收盘的信号，不能用复核日收盘才知道的信号成交。触发卖出后遇不可卖状态则持续等待，不因之后排名回升取消卖单；不在资格池中视为不再满足保留条件。

买入条件、top50、1亿元、5组资金、逐笔释放现金、订单预算与容量控制全部沿用上一轮。为了只比较退出规则，继续允许同股票独立批次叠加；不引入另一套调仓/持仓上限或最优参数搜索。每个轮换时点按该组可用现金等分50份，不对未成交排名递补。

固定三种成本情景：零费用零冲击；20bp基础费加原冲击；50bp基础费加原冲击。共7年×3退出规则×3成本=63组。基础费、冲击仍沿用原入口事前估计；缓冲延长持有后实际卖出冲击未重新估计，这是对照的限制。

各年独立重置资金。年末未触发退出的缓冲持仓按年末价格估值，不假设清仓；区别主动延长持有与触发卖出后被流动性阻挡。比较净收益、换手、费用、回撤、持有时长与未退出数。不因某规则本轮成绩更高而自动替换正式策略。仍有幸存者偏差和日线撮合限制，且这是已知历史上的事后研究。
