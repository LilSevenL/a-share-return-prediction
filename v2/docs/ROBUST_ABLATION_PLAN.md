# 鲁棒损失重点因子组复验

依据已完成的OLS消融，固定复验C条件筛选、M动量反转、F资金流三组。2017–2023七折，每折原20万行样本、原训练期预处理与原目标尺度；等权，L2=0，Huber delta=1.35，tol=1e-5，max_iter=6000。分别移除一组并重新拟合Huber及精确MAE，共42个新模型；完整模型直接使用已核验的上一阶段等权模型。

保持原活跃因子的填补、截尾、缩放和相关性筛选结果。每个子模型有明确输入列、训练样本哈希与检查点身份。预测全年，统一评分键、标签及公共评价权重，保存预测、逐日指标和收敛记录，并独立重算Rank IC。正增量定义为完整模型减去移除组模型；正数表示保留该组更好。

本方案是看到OLS消融结果后开展的历史开发复验，不是新的独立样本检验，不自动选择精简模型。组合删组需要单独训练，单组消融增量不能相加。保持本地2011–2023数据范围，原V1、已有模型和测试边界不变。
