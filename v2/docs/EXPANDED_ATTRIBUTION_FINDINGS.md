# 50万样本回测归因结论

已执行 `attribute_expanded_backtest.py`，覆盖20万/50万两轮、72场景、504个年度账户；年度净损益、股票累计净贡献、实际费用及双边换手均与原回测核对通过。详细表及逐股票parquet保存在 `quant_data/processed/v2/expanded_attribution/`。

在精简模型、20bp往返基础费加冲击下，扩样本年度收益改善数：Huber固定5日3/7、前50保留3/7、前100保留4/7；MAE分别3/7、4/7、5/7。全期收益提高不等于逐年改善。

Huber前100保留：50万相对20万的年度收益差，2017 +1.30、2018 +1.98、2019 −2.45、2020 −0.90、2021 +0.76、2022 −2.02、2023 +2.64个百分点。MAE前100保留：+1.33、+2.70、−0.52、+1.28、+0.02、−0.73、+0.89个百分点。两者2022均退步，不宜称为跨市场状态普遍改善。

50万精简模型年化双边换手从固定5日的约96.7倍降到前100保留的约70.2–70.5倍，仍然很高。Huber前100保留七年累计基础费6784.97万元、冲击5769.95万元；MAE分别6434.01万元、5363.90万元。冲击占累计实际费用约45%–46%，基础费用也不可忽视。它们是各自实际资金路径的累计费用，不是从零成本账户终值直接扣除的数额。

股票集中度必须看两个分母：Huber/MAE前100保留的前10盈利股票，占全部正贡献的5.36%/5.04%，但占最终净利润的29.03%/30.43%。静态扣除这些股票的贡献后，剩余损益仍为正（5074.58/4180.49万元）。固定5日的前10净贡献占最终净利润更高，分别52.65%/62.45%。这不是重新选股或补仓后的反事实回测，也不能证明组合充分分散。

下一阶段优先保持信号与规则不变，做成本及资金规模敏感性，检查净收益在更保守冲击和容量假设下是否仍成立；继续保留Huber和MAE，不因历史收益排名就冻结模型。既有幸存者偏差、日线撮合、历史ST/整手约束不足仍未解决。
