# V2因子数据审计报告

审计日期：2026-10-24。结论：**本轮审计发现正式研究前应修复的问题，暂不建议直接扩大训练或选择模型。** 因子计算的多数基础检查通过，但历史股票池存在明确的幸存者筛选，另有停牌窗口口径不一致及亏损标记定义问题。

## 范围与交付

- 对现有`balanced_500_integration`的80只股票、2022–2023年、38623行、500候选列进行全量质量扫描。
- 使用其2020–2023原始数据回看区间，独立复算66个因子并检查一条收益恒等式，共67项检查。复算没有调用生产因子计算函数；未声称逐一独立重算了全部500列。
- 逐因子输出覆盖率、唯一值数、极端分位数、最小/最大值、数学边界、截面常数天数和分年覆盖情况；相关性使用固定随机种子抽取12000行，至少1000个共同观测，阈值|rho|>=0.98。
- 不读取收益目标、不运行训练、不根据IC筛因子、不读取2024确认期或2025+Test分区。原特征、模型与V1均未覆盖。
- 审计输出：`quant_data/processed/v2/factor_audit_20261024/`，含500项中文清单、JSON/Parquet质量统计、原始公式差异示例、分年统计、相关对和股票池证据。

## 首要发现：历史股票池不是完整历史市场

代码证据：`preprocess_data.py`的`load_universe`只保留`list_status == 'L'`，后续`discover_manifest`只遍历该股票池；`download_all_stocks.py`默认也请求L状态。当前`quant_data/combined/stock_basic.csv`只有5550只L状态股票。

另一个缓存`extra_cache/stock_basic/status_D.csv`有340只退市代码，其中229只的上市区间与2020–2023重叠。核对处理后**全体股票**的2020–2023日线分区，这229个代码均未出现；不是只查80只抽样股票。例子见`universe_audit.json`。

这意味着使用“当前仍上市”的名单决定过去纳入哪些股票，会排除后来退市的历史股票。现有缓存也不保证囊括所有历史状态，229不是历史缺失股票的完整数量。

影响不仅是选股样本：市场等权收益、截面排名和特质收益也依赖股票池。因此即使单因子公式正确，仍不能据此称为无幸存者偏差的全市场研究。

建议：在独立V2数据目录重建按历史上市/退市日期有效的股票池，核对原始缓存，缺失部分再补齐日线、复权及必要衍生数据；同时处理退市前后标签缺失和退出估值。不能仅把名单并入却没有价格，也不能把下载今天的行业分类当成历史分类。本轮没有启动下载或修改上游清洗。

## 五个旧滚动因子的停牌口径差异

| 因子 | 不一致的股票日期数 | 差异性质 |
|---|---:|---|
| amount_ratio_5d | 60 | 旧值非空，连续市场日窗口应为空 |
| amount_ratio_20d | 298 | 同上 |
| volume_ratio_20d | 298 | 同上 |
| turnover_zscore_20d | 298 | 同上 |
| net_mf_ratio_5d | 60 | 同上 |

合计1014个因子单元格，不能解释为1014个不同股票日期。共同有效的位置没有超出所设数值容差的差异。

原因：旧SQL对这些项使用最近N条股票观测并只检查数量；未检查跨越的市场交易日数量。新因子先补完整市场日索引，再要求连续窗口，停牌缺口会使窗口为空。两种定义都可以是研究选择，但不能在目录里声称全部使用统一连续市场日规则。

建议：V2统一按市场日重算这5项，保留V1原结果。修复后重建新版本表并重新训练；不要仅修改目录解释来掩盖定义差异。独立复算已提供差异股票、日期和实际/期望值用于回归测试。

## 亏损标记需要隔离，估值缺失不能简单补零

`negative_earnings_flag`当前定义为`pe_ttm < 0`，但Tushare daily_basic说明亏损PE为空。当前样本该因子覆盖78.58%，所有有效值均为0，不能完成“识别亏损”这一目的。也不能将PE为空直接认作亏损，因为缺失可能还有其他原因。[官方字段说明](https://tushare.pro/document/2?doc_id=32)

建议：隔离该标记，待取得可靠历史可用的TTM利润符号后再实现。原`earnings_yield=1/pe_ttm`也只能在该数据源可用的PE上计算，不能声称已覆盖负盈利收益率。财务修订时点没审计前，不应用现有财务表草率补齐。

股息率TTM覆盖约69.99%，250日股息率z-score约28.03%；长窗口要求完整数据会扩大缺失。不能未经字段语义核查就将空值当成零股息。更短窗口或缺失指示变量可以作为后续设计，但本次不根据2023覆盖情况优化模型。

## 单位、数值与冗余检查

- 现有特征键无重复，无无穷值。抽样原始数据的四张表在被审计80只股票上无重复股票日期；77202条合并日线无非正/缺失复权因子、无OHLC基本关系错误、无负成交量或成交额。
- 67项独立检查中62项没有差异；5项差异均为上述停牌缺失语义。覆盖不同收益窗口、波动率、隔夜/日内收益、资金流单位换算、估值倒数及30个条件筛选因子。
- `daily.amount`是千元，乘1000转元；`moneyflow`金额是万元，乘10000转元。现有跨表资金流比值的10倍换算及新增聚合资金流比值复算通过。[日线单位](https://tushare.pro/document/2?doc_id=27)、[资金流单位](https://tushare.pro/document/2?doc_id=170)
- 旧`log_amount`取千元的对数，新增`log_mean_amount_*`使用元；这是对数尺度的固定单位差，不能直接当作同单位水平比较，但不是资金流比值的十倍计算错误。建议目录明确每项单位。
- 大单分类按订单金额区间，不等于真实机构账户身份；因子解释应写“大单活跃度代理”。资金流接口的净额字段也不能简单假定等于各档买卖额相减之和。[资金流口径](https://tushare.pro/document/2?doc_id=170)
- 发现33对|相关系数|>=0.98。例如成交量筛选与换手筛选的20日下行收益因子相关约0.99985。不是33个重复因子，更不能自动删除其中一列；正式剔除规则必须只在每折训练数据中拟合。
- 构建记录中的4个源码/目录哈希均一致，输入文件大小与修改时间未漂移。这只能说明当前可复现输入一致，不能证明供应商历史数据从未修订。

## 时间边界检查与限制

现有流水线测试中的“追加未来数据不改变历史输出”和“缺失市场日打断新增窗口”通过。审计工具新增3项测试，验证数值误差容忍、空值/数值差异区分和数学边界规则；相关流程7项测试重新通过。

这些测试不能证明所有原始数据在历史信号时点真实可获得。财务修订版本仍未解决；日线/资金流/每日指标须在当日数据完成发布后才能生成信号，不能声称15:00一收盘所有字段已齐。下一交易日执行的时间安排可兼容盘后更新，但仍需记录实际数据可用时间。

本轮没有对所有500列做独立参考实现，没有对全历史全市场逐行审计，没有测试因子预测收益的能力，也没有通过本次质量统计重选模型。
