## 2026-11-15 · 补记：单测、smoke、计时试跑（上一轮会话）

**做了什么**：单测 9/9 通过；`run_lgbm_v2_pilot.py --mode smoke` 修 bug 后跑通；`--mode timing`（2021 / full / 中结构 127 叶·8 层·每叶 0.25% / 200 万行）跑完，exit 0；样本量决定（200 万行）写入计划第 3、9 节。

**改动的文件**：只改了 `v2/experiments/run_lgbm_v2_pilot.py`，`lgbm_v2_common.py` 与单测未改。

1. `lgb.Dataset(...)` 的 `params` 由 `dict(max_bin=..., verbosity=-1)` 改为完整训练参数 `params`，验证集同样传 `params`。原因：LightGBM 4.7 在 `lgb.train` 中尝试修改已构建 Dataset 的 `feature_pre_filter`，报 `Cannot change feature_pre_filter after constructed Dataset handle`，smoke 第一次直接崩溃。
2. `trained_rounds` 由 `booster.current_iteration()` 改为 `monitor.iteration`（回调记录的最后一轮）。原因：早停异常后 `lgb.train` 返回的 booster 已被截断到 best_iteration，`current_iteration()` 报的是最佳轮而不是实际训练轮（smoke 报 30，实际停在 80 = 30 + 耐心 50）。早停逻辑本身正确。
3. `fit_elastic` 中 `fit_preprocessing(x_fit, ...)` 改为先用同一种子 `default_rng(42).choice(len, 50000)` 选出它本来会抽的那 5 万行再传入。原因：`fit_preprocessing` 先把整个输入转 float64 再抽样，200 万行时多占约 6 GB；改后抽到的行集合完全相同（只有行序不同，统计量与行序无关）。smoke 中 Elastic Rank IC 改前改后都是 0.05434，确认不变。
4. 训练开始前重置 `monitor.started`，使每 100 轮耗时不含 Dataset 构建；summary 新增 `peak_memory_gb_after_lgbm_train`。

**结果**（`quant_data/processed/v2/lightgbm_pilot_timing_2021_full_2000000/`）：边界断言通过；标签复核 1000 行最大误差 0.0；elastic_gate_ablation 50 万行 100% 为子集；expanded_losses 重叠 33.55%（≈ 2M / 5.95M，独立哈希的期望值）。训练 980 轮、best 780、未撞上限，训练 104 秒，每 100 轮平均 10.4 秒；峰值内存 10.56 GB；端到端 1288 秒，其中外层逐月取数 + 预测 942 秒。2021 外样本 LGBM Rank IC 0.0663，同 key Elastic 0.0634，NW t 0.37。

**遗留问题**：
- 标签复核与 `build_targets` 用同一价格源同一公式，误差为 0 是预期的，只证明一致性，不是独立来源的验证。
- 每 100 轮耗时从 8.4 秒升到 12.7 秒，可能是笔记本降频；耗时数据有一定噪声。
- 中结构实际平均叶子 42 / 127，深度全部到 8：起约束的是每叶最少样本数和 max_depth。

## 2026-11-16 · 第 3 步准备：Huber 目标核对与标签构建

- **Huber 核对**（`v2/experiments/check_lgbm_huber.py`，合成数据，LightGBM 4.7.0）：单轮、学习率 1、二值特征两叶、无正则、`boost_from_average=False`，叶子值 = −Σgrad / Σhess。在初始分数 0 和 0.02 两种情况下，LightGBM 叶子值与“grad = diff（|diff| ≤ alpha），否则 alpha·sign(diff)；**hess = 1 对所有行**”完全一致（差 ≤ 1e-10）；与“hess 只在 |diff| ≤ alpha 时为 1”不一致（差 1e-4–1e-2）。diff = 当前分数 − 标签。`boost_from_average=True` 时 huber 的初始值 = 标签均值（不是中位数）。含义：Huber 下 H 仍为叶内样本数，λ2 的尺度与 L2 相同，按计划不变；λ1 作用在截断后的梯度和上。官方参数文档只说明 `alpha` 是 Huber 损失的参数，没有写 hess，以上以实测为准。
- **标签构建**（`v2/run_lgbm_v2_stage6a.py --labels-only`，存于 `quant_data/processed/v2/lgbm_stage6a/labels/`，即 D 盘，127 MB；空间充足，未改用 F 盘）：每折取 targets 表中信号日落在内部拟合集日期范围内、原始标签有限的**全部**股票，按信号日当日截面算均值（C）与平均秩（D = (平均秩 − 0.5) ÷ 当日有效股票数），再按样本键接回内部拟合集；断言接回后原始标签与缓存逐位相同、无缺失、D 在 (0, 1) 内；断言参与计算的退出日都早于外层年份 1 月 1 日——实际最大退出日都早于 Y−1 年 1 月 1 日（2015-12-31 … 2019-12-31），没有任何标签进入早停年份。
