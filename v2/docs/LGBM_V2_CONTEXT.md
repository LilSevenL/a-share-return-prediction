## 3. 用户确认过的方案要点（及理由）
- 树的复杂度：实际叶子数 ≤ min(num_leaves, 2^depth, 行数 / min_data_in_leaf)。所以三者要一起设。第一阶段用 3 种结构 × 3 个叶子门槛（按实际拟合行数的比例）。
- 正则化：用 LightGBM 自带的叶子级 L1/L2（lambda_l1 / lambda_l2），逐步筛选。
  - 叶子值 = −sign(G)·max(|G|−λ1, 0)/(H+λ2)：λ1 的尺度跟梯度和走，λ2 的尺度跟叶子样本数走。
  - 标签乘以常数 c 时，λ1 按 c 缩放，λ2 不变。其他标签变换（去均值、排名、Huber）要重新检查 λ1。
- 学习率和早停单独调（第四阶段）。早停变体在保存好的曲线上离线比较。
- 用户要求加入的项目：
  1. 同 key 的配对线性对照（Elastic Net）
  2. Newey-West 显著性（lag 5）
  3. 择时 / 选股拆分诊断
  4. 多种子平均（42 / 7 / 2026）
  5. 与现有 333 因子门控 Elastic Net 做固定 50/50 混合
  6. 日度截面排名特征
  7. path_smooth 检查
- 保留 max_bin、feature_fraction、bagging、extra_trees 的单因素检查（第三阶段）。
- 448 和 333 两套特征都跑（第五阶段）。

3. 第七阶段（种子，筛选流程）：F1–F3 各用种子 7、2026 补跑五折（种子 42 已有）。种子只通过 feature_fraction 抽样起作用（bagging 关）。报告每个种子的分数、跨种子标准差、三种子平均预测的分数，以及 F1–F3 的排名是否随种子改变。
4. 第八阶段（复核流程）：轮数沿用同一种子在筛选流程中的 best_iteration（按轮数，不按样本量放大），在该折完整 200 万行样本上重训，预测外层年份；三种子预测取平均。min_data_in_leaf 按 200 万行实际行数计算；λ1 沿用该折筛选流程的值；D 标签按完整样本重建（每日统计仍用当日全部股票，断言退出日 < Y-01-01）。Elastic(D) 主对照同步在完整 200 万行上重拟合。
5. 最终选择按第 8 节平台规则（含实际意义门槛），在复核分数（三种子平均）上进行：先找最高分，与它的差距不到门槛的都算平台成员，在平台里选更简单的（叶子少、深度浅优先；中结构比深结构简单；同结构 λ2 更大视为正则更强）。
6. 冻结：最终配置、代码哈希、各折样本键哈希、三个种子、每折轮数规则（同流程：内部拟合 + 早停定轮数 → 完整 200 万行按该轮数重训）写入 frozen_config.json。冻结之后不再改任何东西，再进入第九阶段（2022、2023 确认、融合、回测）。
7. 更正（2026-11-19）：第 4 条中"完整样本可由 fit + es 缓存拼出"的判断有误。缺口来自两处：(a) 信号在 Y−2 年末、退出在 Y−1 年初的跨年行，既不在内部拟合集（退出日 ≥ Y−1-01-01）也不在早停集（信号不在 Y−1 年）；(b) 早期折完整样本中 Y−1 年的行多于 30 万，超出早停集的前 30 万行。评审批准按建缓存时相同的取数方式补齐缺失行，并断言与已有缓存共有的键逐值相同。

## 14. 第九阶段评审结论（2026-11-20，评审会话）

确认期结论（冻结配置，不再更改）：

评审判断的原因（待诊断确认）：
1. Rank IC 是全截面指标，交易只用前 50 名。G1 在 2022 年 Rank IC 高于 G3，但 Top50 超额只有一半（0.45% 对 0.91%），说明树模型的排序优势主要在截面中部或尾部（识别会跌的股票），而 A 股只能做多。选择口径从头到尾都是全截面 Rank IC，没有约束头部，这是方案设计上的缺口。
2. 冻结流程依赖单一年份早停集：2023 折早停集（2022 年）在约 130 轮见顶，最终模型只有 110–160 棵树，基本没训练。第一阶段就记录过"单年早停集"的风险，第四阶段 R6（固定树数）也被测过，但因为没过实际意义门槛被否决。
3. 树模型优势在年份上明显衰减（资格池 Rank IC 领先：2017–2018 约 0.08，2021–2023 约 0.01–0.03），比选择偏差能解释的大得多；更像是 2021 年后这类信号（规模、流动性、波动的非线性）的拥挤或衰减。安慰剂通过、确认期优势仍为正，没有证据表明存在泄露。
4. 2017–2021 回测（原冲击 +397%）的绝对数字不可信：配置在这五年上选出，而且收益高度依赖这几年的特定风格。
