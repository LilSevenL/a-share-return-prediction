## 结论

1. **按机械规则，P4 = lr 0.01 + R1**（当前早停规则，耐心 400 轮，上限 16000）。资格池选择分数 0.12949，基准（lr 0.02 + R1）为 0.12930：分数差 +0.00019，日度均值差 +0.00020，NW t = 1.07，**实际上与基准没有差别**。
   - **选择过程**：从最大学习率开始逐个比较。0.05 起步 → 0.03 对 0.05 满足门槛（+0.00121，t 3.79），换成 0.03 → 0.02 对 0.03 只高 +0.00086，不足 0.001，不换 → 0.01 对 0.03 满足门槛（+0.00105，t 4.52），换成 0.01。
   - **0.01 下的早停规则**：R2–R6 都没有对 R1 同时满足分数差 ≥ 0.001 且 t ≥ 2。R3 +0.00020（t 2.76）、R5 +0.00018、R6 +0.00015，最接近，但都不够。
2. **lr 0.03 / 0.02 / 0.01 在 R1 下相差不到 0.001**，lr 0.05 明显更差：比 0.02 低 0.0021，t −6.5。所有组合都没有截断，也没有负折。
3. **复核**：P4 的 lr ≠ 0.02，所以按计划用 lr 0.01 + R1 复核了 (λ1 ×1, λ2 = 1000)，五折。
   - 资格池分数 0.12961；对 P4 +0.00012，t 0.92。
   - 全样本分数 0.1308；无截断。
   - 结论：在平台内，只报告，不改选择。
4. **确定性核对全部通过**：lr 0.02 的五折都完全重现了第三阶段基准。
   - 早停集曲线在第三阶段训练过的全部轮次上逐点相等，共 322 / 431 / 428 / 506 / 478 点，最大差 0.0。
   - 树数相等；第三阶段最佳树数处的外层预测相同。
   - R1 在曲线上离线选出的轮数 [3020, 4110, 4080, 4860, 4580]，与第三阶段实际早停的结果完全一致，说明离线早停模拟正确。

   - 早停集资格池用与外层相同的函数补算，该函数对外层键的结果与缓存完全一致。

## 可疑之处与需要评审判断的问题

1. **lr 比较的读法会改变结果**。我的实现是把较小 lr 和"当前已选的 lr"比较：0.02 没有胜过 0.03，所以 0.01 拿去和 0.03 比，而不是和 0.02 比，结果通过了门槛。
   - 如果读作"只和相邻的较大 lr 比"或"要胜过所有更大的 lr"，0.01 对 0.02 只有 +0.00019（t 1.07），不通过，选中的会是 **lr 0.03**。
   - 在 lr 0.03 下，**R6 对 R1 满足门槛**（+0.00104，t 3.35），这条结果只作报告，见 C2 节。那样的建议会是 **lr 0.03 + R6（固定 3200 棵树）**，分数 0.1295，对基准 +0.00018，t 0.67。
   - 三个结果（0.01+R1、0.03+R6、0.02+R1）彼此相差不到 0.0002，都在平台内。差别只在训练成本：lr 0.01 的训练时间约是 0.02 的 2.4 倍，模型约是 2 倍大。请评审定这条规则的读法。
2. **大部分"跳过轮次"其实是树停止生长**。在 P3 的正则化（λ1 ≈ 200、λ2 = 10000）下，每个 lr 到一定轮数之后就再也没有加树；第一个不加树的轮次与总树数几乎相同。
   - 停止生长的位置：lr 0.05 约 2000–2300 轮，0.03 约 3200–3850，0.02 约 4560–5950，0.01 约 9000–11250。
   - 因此"训练到上限"实际上是训练到不再分裂；外层曲线的最后一点与峰值相差 ≤ 0.0008。
   - 这时正则化本身起到了早停作用，早停规则的影响很小：峰值 − R1 处的值，在 0.02 下最大 0.0007，在 0.01 下最大 0.0012。
   - 后续若改变 λ 或特征，这个性质可能不再成立。
3. **R1 在 lr 0.05、0.03 下停得过早**（例如 0.05 下 2017 年在 880 轮，0.03 下在 1540 轮），离外层峰值差 0.002–0.003。耐心按 lr 线性缩放之后，大学习率下早停集曲线的波动足以提前触发停止。R6（固定轮数）在大 lr 下明显更好，在小 lr 下和 R1 没有差别。
4. **耗时统计受电脑睡眠影响**：2019 复核拟合的训练时间 30471 秒，正常约 1700 秒；2020 lr 0.01 为 3364 秒，正常约 1800 秒。结果是确定性的，不受影响。下表的耗时请看其余各折。
5. **R6 的统一树数可直接用于冻结**：lr 0.01 为 9000，0.02 为 4500，0.03 为 3200，0.05 为 1900，都没有截断。按树数定义；有跳过轮次时，各折对应的轮数见表。

## A. 规则定义与实现细节

- **耐心**：R1 = 200 × 0.02 / lr 轮，即 80 / 133.3 / 200 / 400 轮；R2 取一半，R3 取两倍。判定逻辑与训练时的早停回调相同：每 10 轮评估一次，"当前轮 − 最佳轮 ≥ 耐心"时停，所以非整十的耐心实际向上取到 10 的倍数。
- **R4**：早停集全样本指标取最近 3 次评估的滚动均值，从第 3 次评估起才有值；只有高于当前最佳 0.0001 以上才算改善，耐心同 R1。
- **R5**：早停集资格池指标，耐心同 R1。
- **R6**：对每一折，用其余四折外层资格池曲线在共同网格（每 100 棵树）上的平均值，取峰值处的树数作为该折的树数。另外报告五折统一的树数。R6 按树数定义，判截断时换算成该折首次达到这个树数的轮数。
- **取轮数**：R1–R5 选中的轮数先换算成树数（逐轮树数），再取最近的外层曲线点（每 100 棵树一个点，外加最后一点）。取整误差最大 50 棵树，按折和规则列在下表最后一列。
- **截断**：选中轮数 ≥ 0.95 × 上限，任一折满足即为截断。本轮没有。
- **lr 选择的实现**：按 0.05 → 0.03 → 0.02 → 0.01 的顺序，较小 lr 与"当前已选 lr"比较，满足门槛才替换；见可疑之处第 1 条。早停规则：在选定的 lr 下，非 R1 规则对 R1 满足门槛才采用；有多个满足时取分数最高的。
