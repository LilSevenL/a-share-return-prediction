# V2 LightGBM 阶段 6a（标签与损失）结果

日期：2026-11-17。按计划第 7 节第六阶段 A–D 与第 13 节修订执行（6a 提前到第三、四阶段之前）。**只报告建议，由评审确认；未进入第三阶段（采样）或第四阶段（学习率）。** 执行记录见 `LGBM_V2_WORKLOG.md`。

## 设置

- 基础配置 P* = 深 0.1%（num_leaves 511、max_depth 不限、min_data_in_leaf = 0.1% × 内部拟合行数）、λ1 = 50、λ2 = 1000、path_smooth = 0（第二阶段收尾机械规则确定，见 `LGBM_STAGE2_RESULTS.md` 第 I 节）。其余参数与第二阶段相同：lr 0.02、上限 6000、耐心 200、feature_fraction 0.3、448 因子原始值、五折 2017–2021。
- 方案：A = L2 + 原始收益（复用 P* 的第二阶段结果）；B = Huber + 原始收益（alpha = 该折内部拟合集原始标签 1.35 × MAD）；C = L2 + 每日截面去均值收益；D = L2 + 每日截面排名收益 (平均秩 − 0.5) ÷ 当日有效股票数。
- C、D 的每日统计用 targets 表中当日**全部**有有限原始标签的股票（不只是抽样行），只用信号日当日截面，按样本键接回内部拟合集；断言接回的原始标签与缓存逐位相同、所有参与计算的退出日早于外层年份 1 月 1 日（实际全部早于 Y−1 年 1 月 1 日）。
- 早停指标与所有评分始终用**原始收益**的日度 Rank IC（选择口径为资格池）；只替换内部拟合集的训练标签。
- λ2 不变；λ1 起点：B = 50；C、D = 50 × (变换后标签 std ÷ 原始标签 std)，两位有效数字，逐折（C 37–38，D 200–210）。λ1 复核：第一轮最佳非 A 方案为 D，C 与 D 显著不同（t = −8.12），所以只对 D 做 λ1 × {0.5, 2}。
- Huber 目标核对（`v2/experiments/check_lgbm_huber.py`）：LightGBM 4.7.0 的 huber 梯度 = diff（|diff| ≤ alpha）或 alpha·sign(diff)，**二阶导对所有行都是 1**，初始值为标签均值；因此 Huber 下 H 仍是叶内样本数，λ2 不需换算。
- 每个拟合另外记录择时方差占比与“每日预测均值与每日实际平均收益的相关”。输出 `quant_data/processed/v2/lgbm_stage6a/`（`variant_table.csv`、`fits_table.csv`、`pairwise_nw.csv`、`stage6a_summary.json`、`stage6a_tables.md`、`labels/`）。

## 结论与建议

1. **资格池选择分数**：D 0.1296 > C 0.1164 > B 0.0881 > A 0.0827。D 在五折中每一折都最高；C 每折都高于 A、B。
2. **两两比较全部显著**：D − A = +0.0502（NW t = 12.99），C − A = +0.0366（t = 10.04），D − C = +0.0136（t = 8.12），B − A = +0.0047（t = 2.31）。
3. **λ1 复核**：D 的 ×0.5（0.1292）与 ×1（0.1296）几乎相同，×2（0.1239）五折全部变差；取 ×1。
4. **建议（按采用规则，由评审确认）：采用方案 D（L2 + 每日截面排名收益），λ1 = 200–210（换算后 ×1）**。D 对 A 的 NW t = 12.99 ≥ 2。
5. 对同折 Elastic（原始标签）的配对 t：D 在 2017–2020 为 8.5–10.4，2021 为 3.90——2021 首次在所有方案中都显著。

## 可疑之处与需要评审判断的问题

1. **效应异常大，已做独立核对**：C、D 相对 A 提升 0.037–0.050（相对提升 45–60%），远大于结构与 λ 网格的全部影响（约 0.005）。用 scipy `spearmanr` 对 2017 年 C 与 A 的保存预测和缓存原始标签独立重算资格池日度 Rank IC，结果与流水线完全一致（A 0.1081、C 0.1484）；C 与 A 的每日截面排名相关只有 0.59，是实质不同的模型。没有发现泄露途径：变换标签只用于内部拟合集训练，退出日都早于 Y−1；早停与评分用原始标签；外层只用因子。机制上合理：原始 5 日收益中市场整体涨跌占很大方差，L2 在原始标签上把容量花在“择时”上（A 的择时方差占比 0.139，C 0.021、D 0.036），而 Rank IC 只看截面。
2. **线性对照不再同口径**：计划第 5 节规定“第五、六阶段的样本筛选与标签变化，线性对照组同步执行”。本次任务未要求、我也没有对 Elastic 做同样的标签变换；表 C 中对 Elastic 的 t 是“D 标签 LightGBM 对原始标签 Elastic”，**不能**用来判断“树模型相对同口径线性模型的增量”。树相对线性的增量很可能部分来自标签而非模型；建议评审决定是否补跑 Elastic 的 C、D 标签版本（每折一次，计算量很小）。
3. **前面各阶段都是在原始标签下调的**：结构（深 0.1%）、λ（50, 1000）、早停与轮数都在 A 下选出；D 的最佳轮数在 2021 折从 260 变为 4080，五折过拟合差距（内部−早停）由 0.154 变为 0.218。若采用 D，P* 的结构与 λ 是否仍合适需要评审判断（计划第 13 节第 5 条的理由正是“λ、轮数依赖标签尺度”）。
4. **换手更高**：D 的相邻日 Top50 重合 0.340（A 0.382），头部收益差 Top50−池 0.0109（A 0.0080）。扣费后的净效果要到第九阶段回测才能看。
5. **跳过轮次**：λ1 ≥ 100 的拟合（第二阶段 (100, 1000)、(200, 1000)，6a 的 D ×0.5 / ×1 / ×2 部分折）出现“该轮不加树”，最多 217 轮；其中若干折有 2–17 次发生在最佳轮之前，已按逐轮树数取最佳模型（见 WORKLOG）。
6. **B（Huber）**：显著优于 A 但幅度小（+0.0047，t = 2.31），且 2017 折反而低于 A；远不如 C、D。

**离线诊断（只读已保存的预测与缓存，无新拟合）**：
- 安慰剂预测与真实 D ×1 预测的每日截面秩相关均值 0.013，与 A 为 −0.005——安慰剂模型没有学到 D 模型的排序，看不出标签信息泄露。
- 它与几个流动性 / 波动类因子有小幅相关：small_order_net_ratio 0.096、log_amount −0.086、high_low_range −0.059、garman_klass_vol_20d −0.057。噪声标签训练出的树是“因子的随机函数”，这类因子在 2021 年本身有持续的截面 IC，随机函数会以小权重继承它们。
- 安慰剂的日度 IC 标准差 0.055，一阶自相关 0.71，正值天数 61%；高自相关使有效样本很少，0.012 的均值只对应 t = 1.79。
- 解释（供评审判断）：更像单次随机抽样的偶然值，而不是泄露；但单个种子无法区分“偶然”与“系统性偏差”。可选做法（未执行，需评审决定）：用多个种子（例如 5–10 个）跑安慰剂得到零假设分布，再看真实 D（0.091）是否远在分布之外；或把通过标准改为相对标准（例如 < 真实值的某个比例）。
