# OLS固定诊断对照

本轮只诊断，不修改OLS模型，不选取最优参数。2017–2023逐年独立重置1亿元、top50、5组资金、信号日5000万元成交额与上市60日条件沿用。

对两种资金规则各运行四个固定情景：无基础费无冲击、仅20bp基础费、仅既定冲击、20bp加冲击。旧规则等待整组最后退出；新诊断规则只锁未卖出的头寸，在原5日轮换时点把该组前一日收盘已到账现金等分50份下单。同一股票可有独立重叠批次，未成交不递补，无借款，当日收盘卖出所得不能用于当日开盘买入。新增规则只作敏感性对照，不据结果自动替换旧规则。

成本情景差额含复利、资金规模、容量门槛等路径效应，不当作严格线性成本归因。另按成交明细拆分实际基础费用与冲击费用。

信号诊断在交易资格池先排名，再检查标签：每天前50、后50、全池的已知五日简单收益（由raw对数收益转换）、缺失覆盖与前50减全池差值。只比较两组均有观测的相同日期；前50缺失不递补。它们是重叠五日标签描述，不是可交易组合收益或正式市场基准超额收益。

保留日线撮合、幸存者偏差、缺失涨跌停、非历史实际费税、无ST与整手约束等限制；不得把本轮对照当成新的独立测试。
